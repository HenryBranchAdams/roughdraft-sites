## Extend UI File System

The Markdown document navigator adapts the flat-manifest model, derived folder
hierarchy, Finder-style icon/list/column/gallery views, search, sorting,
keyboard behavior, responsive view selector, and `onFileOpen` seam from
[`@extend/file-system`](https://www.extend.ai/ui/docs/components/file-system) at
[`extend-hq/ui` commit `7d7c8ec`](https://github.com/extend-hq/ui/tree/7d7c8ec).
The adaptation is intentionally Markdown-only and does not include Extend UI's
PDF or Office viewers.
